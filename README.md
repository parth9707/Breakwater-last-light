# Breakwater | Last Light

A self-contained interactive HTML experience with a dark coastal atmosphere, cinematic styling, and responsive layout.

## Files

- `parth1.html` — the complete standalone web experience.

## Run locally

Open `parth1.html` directly in a modern web browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000/parth1.html>.
